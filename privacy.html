Política de Privacidad

Última actualización: 21 de octubre de 2026.

Nota: RZ CLIPING continúa en desarrollo. Estos documentos deben revisarse por el responsable y completarse con un contacto público antes de solicitar la aprobación de TikTok.

1. Responsable y alcance

Esta política describe el procesamiento de datos en la aplicación para macOS RZ CLIPING. Responsable: titular del proyecto RZ CLIPING. Contacto público minegocion07@gmail.com. No se debe presentar esta página como versión definitiva hasta verificar el funcionamiento real de la aplicación y añadir dicho contacto.

2. Archivos y datos que se procesan

Cuando el usuario selecciona videos, RZ CLIPING puede leer archivos audiovisuales, metadatos técnicos, duración, pistas de audio y fragmentos visuales para crear clips. Las exportaciones, los subtítulos y el historial de recortes pueden almacenarse en carpetas locales del Mac. Para reducir duplicados, el historial puede guardar rutas, intervalos de tiempo y referencias a clips procesados.

3. Importación por Internet y búsqueda

Al utilizar una URL o herramientas experimentales de descubrimiento, la aplicación se conecta a plataformas de origen y puede transferir datos necesarios para resolver y descargar los fragmentos autorizados. Los terceros pueden recibir datos técnicos de conexión como dirección IP y registros de acceso de acuerdo con sus políticas. RZ CLIPING no garantiza que las fuentes externas mantengan formatos o disponibilidad estables.

4. Subtítulos y transcripción

El sistema de reconocimiento de voz de Apple puede requerir permisos del sistema y, según idioma y disponibilidad, utilizar servicios de Apple. Por ello, no se afirma que todo el procesamiento de transcripción ocurra siempre sin conexión. Los archivos SRT producidos pueden guardarse en la carpeta de resultados elegida por el usuario.

5. TikTok y sesiones

La ventana integrada de TikTok utiliza WebKit, que puede almacenar cookies y datos de navegación asociados a las páginas visitadas. La sesión web no implica acceso autorizado a una API para publicar videos. Actualmente RZ CLIPING no tiene una conexión OAuth de publicación automática en TikTok activa y no publica a través de esa API.

En caso de implementar la API, se informará sobre permisos solicitados, datos de cuenta accesibles, protección de credenciales, duración de los tokens, revocación de acceso, tratamiento de registros y posibles transferencias a TikTok antes de activarla. No se pedirá al usuario que entregue su contraseña de TikTok al desarrollador.

6. Finalidades y conservación

La información local se procesa para editar, exportar, organizar y evitar duplicaciones. Los archivos y registros pueden permanecer en el dispositivo hasta que el usuario los elimine. Las copias alojadas por servicios externos están sujetas a los plazos y controles de dichos proveedores. La aplicación todavía no incluye un sistema centralizado verificado de eliminación de datos de terceros.

7. Uso compartido y terceros

No se debe interpretar esta política como una afirmación de que todos los datos permanecen exclusivamente en el Mac. Pueden intervenir Apple Speech, TikTok, YouTube y los servicios que el usuario decida abrir. No se declara una comercialización de datos del usuario por la aplicación; antes de habilitar futuras integraciones se revisarán las prácticas de intercambio y se actualizará esta sección.

8. Seguridad

Se procura minimizar el acceso a información no necesaria. Como cualquier software en desarrollo, no se garantiza seguridad absoluta. Se recomienda no compartir contraseñas, claves API ni tokens por mensajes y mantener el Mac protegido con las actualizaciones disponibles.

9. Derechos y opciones de control

El usuario puede dejar de usar la aplicación, eliminar sus exportaciones y registros locales, controlar permisos en macOS y gestionar sus sesiones o revocar autorizaciones desde los servicios externos. Para consultas sobre tratamiento de datos hará falta un canal de contacto público y operativo, minegocion07@gmail.com.

10. Actualizaciones

Esta política se actualizará antes de poner en funcionamiento capacidades nuevas que procesen información adicional, especialmente autenticación, estadísticas o publicación automática en redes sociales.
